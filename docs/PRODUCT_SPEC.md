# 台北車站通產品規格

狀態：限定路線的本機原型程式碼。必要素材另行授權與準備；此 repository 不含可直接使用的導航資料包，也不攜帶歷史測試結論。

## 路線與旅程

範圍為 B1 的 Y28 → Y26 → Y23 同方向三節點。終點是 Y23 固定牆標，不代表地面出口、月台或站外目的地。

| ID | 必須保留的行為 |
|---|---|
| NAV-01 | 使用者明確啟用後才請求相機；可暫停、恢復、結束或改用人工確認。來源須可區分。 |
| NAV-02 | 相機 decoded pixels 經固定牆標與周圍脈絡比對，再通過時序及節點順序條件，才能更新進度。倒數、播放時間及地圖操作不能產生抵達。 |
| NAV-03 | 模糊、未知、錯序、舊影格及中斷不推進節點；保留上次有效進度並提供復原。人工事件不冒充視覺辨識。 |
| NAV-04 | 主畫面以相機影像為底層。地標標籤來自本次像素匹配的影像座標；裁出可見區、未知、暫停或證據過期時清除，不提供世界座標 AR 或連續藍點。 |
| NAV-05 | 底部呈現當下指引、歷史步行參考及常駐小路線圖。小圖只讀取 session，標示上次更新地標及下一目標，不依時間移動。 |
| NAV-06 | 點小圖可展開本段路線；另有平面圖切換、縮放、捲動及返回介面。官方平面圖需另備，僅供區域參考，不疊精準位置。圖資缺失時可重試或返回。 |
| NAV-07 | 照片重播將核准素材送入相同辨識流程，明示示範來源；不能當作獨立拍攝、實機或現場成功證據。 |
| NAV-08 | 完成畫面區分視覺與人工來源，停止不必要的相機資源；重新開始需新 session 與有效證據。 |

時間是依上次地標提供的粗略歷史參考，不是即時 ETA。路線圖為非比例示意，官方圖的年份與原看板「現在位置」不能當成目前實景或使用者定位。

## 資料與隱私

資料契約見 [contracts](contracts/)，人工路線格式見 [manual route schema](../data/mvp/manual_visual_route.schema.json)。格式合法不代表資料有權使用、地標確實存在或導航已驗證。

相機影像預設只在裝置記憶體處理，不錄音、不儲存或自動上傳。診斷只供使用者主動本機匯出，仍需人工檢查後才可分享。資料準備與排除範圍見 [LOCAL_ASSETS](LOCAL_ASSETS.md)。

## 驗證界線

`npm test` 只驗純程式單元行為，不涵蓋私人素材、瀏覽器相機硬體或實際車站。新素材需獨立驗證辨識與拒絕能力，不能以 metadata 或 readiness 旗標取代證據。

目前尚未通過獨立素材泛化、iPhone 實機、車站 Ground Truth 或陌生使用者驗收。完整車站、多樓層、任意目的地、連續定位、無障礙通行安全、原生 App 及商店發布均不在這份程式碼交付的完成範圍。
